Play your hand.

TrendDeck is free and open source. There's no installer yet, so for now you run it from source. You need Node.js 22.12 or newer.

Terminal 
git clone https://github.com/JoshWright22/TrendDeck.git
cd TrendDeck
npm install
npm run dev

The first npm install also downloads Electron, so it takes a minute.

Get it on GitHub MIT license

If it ever goes the wrong way, fork it and build the one you want.
