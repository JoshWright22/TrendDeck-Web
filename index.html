No new bill

Bring your own sub.

Chat runs on the subscription you already pay for. If one of these is set up on your computer, TrendDeck can use it.

  • Claude Code claude auth login
  • Cx Codex codex login
  • Cursor agent login
  • Gk Grok Build grok login
  • OpenCode opencode auth login
  • Antigravity sign in with Google
  • Qwen Code qwen
  • Kimi kimi
  • Any CLI or API Settings > Agents

Anything else plugs in too. Give it a command to run, or an OpenAI-compatible API URL and key. Everything but chat works without one.

Your computer no server

%APPDATA%\TrendDeck
  trenddeck.json   brands and sites
  Partitions\
    pixel-forge\   logins
    loaf-lab\      logins
    trail-mutt\    logins

It all stays on your machine.

No sign up to get in and nothing sent off to a server. Your brands and logins are files in one folder.

  • No account, no server
  • Brands and sites in one json file
  • Logins in one folder per brand
  • Delete a brand and its logins go with it

MIT and fully open

Don't like something? Fork it.

All of it is on GitHub. Change what bugs you and build the one you want. You need Node.js 22.12 or newer.

Terminal

cd TrendDeck
